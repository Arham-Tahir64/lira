# Phase 1 interface direction

Visual thesis: a calm, off-white work surface with graphite navigation, clear typography, and a single muted violet accent.

Content plan: persistent organization navigation; project heading and primary task action; readable task rows or status columns; secondary task details. No marketing hero or invented activity.

Interaction thesis: short focus/hover transitions clarify selectable work; an accessible dialog brings task creation into focus; view changes stay immediate and respect reduced motion. Status changes use native selects, so drag-and-drop is not required.
